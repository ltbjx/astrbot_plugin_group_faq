# 群问答自动应答器（AstrBot 插件）

> 仓库：https://github.com/ltbjx/astrbot_plugin_group_faq

粉丝群里天天问同样的问题（汉化在哪、源码在哪、群文件怎么找……）。
这个插件在群里**静默监听**，用**纯本地**的关键词 + 字面相似度判断这句话是不是在问这些主题：

- **命中** → 立刻自动回复你预设的内容
- **没命中** → 什么都不做，也不触发大模型

> 判定过程不调用任何模型/网络接口，**0 token**、毫秒级、离线可用。

---

## 1. 工作原理（为什么省 token）

```
群消息
  ↓
① 看起来像指令？（以 / 开头） → 是 → 跳过（交给指令处理）
② 在生效群里？（only_groups） → 否 → 跳过
③ 像提问吗？（问号 / 怎么 / 在哪 / 吗 结尾…） → 否 → 跳过
④ 关键词命中？ → 是 → 回复
⑤ 字面相似度 ≥ 阈值？ → 是 → 回复
⑥ 都没命中 → 静默返回（不产生任何 token 消耗）
```

命中后会调用 `event.should_call_llm(False)`，避免「插件回复 + 大模型再答一遍」的双回复，也不会因为这句话触发 LLM 计费。

## 2. 安装

```bash
# 放到你的插件目录
cp -r astrbot_plugin_group_faq <你的 AstrBot>/data/plugins/
# 控制台 → 插件管理 → 重载插件
```

无额外依赖（`requirements.txt` 为空占位）。

## 3. 配置（控制台 → 插件配置）

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | 开 | 总开关 |
| `only_groups` | 空 | 生效的群号；**留空 = 所有群**，建议只填粉丝群 |
| `rules` | 3 条示例 | 问答规则：主题名 + 关键词 + 示例问法 + 排除词 + 回复内容 + @ + 冷却 |
| `require_question` | 开 | 只回复问句（防止聊天提到关键词就被答） |
| `question_words` | 20 个词 | 问句词表，如 怎么/在哪/有没有/教程… |
| `fuzzy_enable` | 开 | 关键词没完全命中时用相似度兜底 |
| `fuzzy_threshold` | 0.45 | 模糊阈值，越高越严格 |
| `group_cooldown_seconds` | 20 | 同群两条自动回复的最小间隔 |
| `stop_llm` | 开 | 命中后阻止本条消息走大模型（省钱 + 防双回复） |
| `reply_suffix` | 空 | 每条回复末尾追加的话（如「以上为自动回复」） |
| `debug` | 关 | 把每条消息的匹配结果写进日志，调关键词时开 |

### 怎么配一条规则

以「汉化」为例：

- **主题名**：汉化相关
- **关键词**：`汉化`、`中文包`、`汉化包`、`翻译`
- **示例问法**（可选，提升模糊命中）：`汉化包在哪下载`、`有没有中文版`
- **排除词**：`不需要汉化`、`不用汉化`
- **回复**：
  ```
  汉化文件在群文件 → 「汉化」文件夹里，下载后按里面的说明替换就行。
  ```
- **@ 提问的人**：开

> 关键词别写单字（如「码」），容易误触发；2~8 个字的中文短语最好。

## 4. 指令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/faq` 或 `/faq help` | 所有人 | 查看用法和已配置主题 |
| `/faq list` | 所有人 | 列出所有主题及关键词 |
| `/faq test 文本` | **管理员** | 模拟测试：这句话会命中哪条规则、会回复什么（**不会发到群里**） |
| `/faq status` | 所有人 | 查看开关、生效群、阈值等状态 |

别名：`/问答`、`/问一下` 等价于 `/faq`。

调关键词时最有用的是 `/faq test`：先在群里发 `/faq test 汉化包在哪下载`，看是否命中，再决定要不要补关键词。

## 6. 常见问题

**Q：会不会把正常聊天也答了？**
默认 `require_question=true`：只有问句才回复。「我今天看了汉化教程」不会触发；「汉化在哪下载」会触发。还可以给每条规则加排除词。

**Q：为什么有时候不回复？**
看三个原因：没命中关键词 → 用 `/faq test` 确认；在冷却期（同群 20 秒 / 同主题 5 分钟）；或句子不像提问。

**Q：能不能让它回复时把群文件直接发出来？**
OneBot 对群文件的支持有限（需要文件 file_id，链接还会过期），所以当前版本用「文字指引」回复，更稳。想发链接的话，直接把网盘 / GitHub 地址写进回复内容即可。

**Q：会不会消耗 token？**
不会。整个判定和回复都在本地完成，不走大模型；命中后还会阻止 LLM 再答一遍。
